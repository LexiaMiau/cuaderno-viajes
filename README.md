# Cuaderno de viaje

Prototipo de app web minimalista para organizar viajes, estilo "Notion para viajes".

- **Dashboard** con tus viajes (próximos y pasados) y botón para crear uno nuevo.
- **Editor por días** con bloques: texto, alojamiento, vuelo, ruta (GPX de Wikiloc) y Plan B / Clima.
- Todo es editable: nombre del viaje, fechas, destinos, nombre de cada día y el contenido de cada bloque.
- Reordena los bloques arrastrando el asa (⋮⋮) y añade nuevos con el menú "/".

**Ver online:** https://lexiamiau.github.io/cuaderno-viajes/

**En local:** abre `index.html` en el navegador (necesita internet para cargar Tailwind, Leaflet y las tipografías).

> De momento no guarda los datos: al recargar la página vuelve a los viajes de ejemplo.
